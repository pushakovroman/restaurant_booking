# Система бронирования в ресторане «Aura Gastronomy» (Qt GUI + SQLite + C++17)

Полнофункциональное настольное приложение на **C++17** с графическим интерфейсом на фреймворке **Qt (Qt5 / Qt6 Widgets)** и реляционной базой данных **SQLite (`QtSql`)**. Разработано в рамках университетской лабораторной работы и готово к публикации на GitHub.

## Ключевые возможности

1. **Интерактивная 2D-карта зала (`FloorMapWidget` на `QPainter`)**
   - Графическая отрисовка схемы зала со сглаживанием (`Antialiasing`): *Панорамные окна*, *Летняя терраса*, *Основной зал*, *Барная стойка* и *VIP-каминная*.
   - Отображение каждого из 12 столов с мебелью (стулья/диваны), кодом (`W1..B2`), вместимостью и цветовой индикацией в реальном времени: 🟢 **Свободен**, 🟡 **Забронирован (Онлайн)**, 🔴 **Занят (Гости за столом)**.
   - Выбор любого столика кликом мыши на 2D-карте с мгновенным выводом карточки стола, рейтинга по отзывам, почасовой шкалы занятости с `10:00` до `23:00` и быстрыми кнопками бронирования.
2. **Онлайн-запись + Режим «В ресторане / Хостес» (`Walk-in`)**
   - **Онлайн-бронирование**: выбор даты, времени, длительности, числа гостей, повода визита, особых пожеланий и формирование корзины предзаказа со **скидкой 5%**.
   - **Терминал Хостес (`Walk-in`)**: мгновенная посадка гостей «с улицы» с проверкой свободного окна до следующей брони, перевод брони в статус «Гости за столом (`Check-in`)», закрытие счета (`Check-out`), отмена и **Лист ожидания (`Waitlist`)**.
3. **Умные рекомендации под запрос гостя**
   - **Подбор столика**: многофакторный скоринг (`0..100 баллов`) с учетом вместимости, повода визита (Свидание, Деловая встреча, День рождения, Семейный ужин), пожеланий (у окна, тихая зона, розетка 220В, диваны) и среднего рейтинга стола.
   - **Гастрономический сомелье**: автоматический подбор сбалансированных сетов (закуска + горячее + напиток + десерт) под бюджет, диетический тег (`#вегетарианское`, `#без глютена`, `#морепродукты`, `#легкое`) и лимит калорий с добавлением сета в предзаказ в 1 клик.
4. **Интерактивное меню ресторана**
   - Фильтрация по категориям, диетическим тегам, максимальной цене и ключевым словам, просмотр КБЖУ и времени подачи, а также добавление новых блюд напрямую в базу SQLite.
5. **Комментарии, отзывы и Аналитика**
   - Отзывы гостей с оценками от `1` до `5 ★`, привязкой к конкретному столику и блюду, ответы управляющего ресторана и панель аналитики (почасовая загрузка зала с индикаторами `QProgressBar` и расчет выручки).
6. **База данных SQLite (`data/restaurant.db`)**
   - Все данные хранятся в едином файле реляционной СУБД SQLite 3 (`tables`, `dishes`, `reservations`, `preorder_items`, `reviews`, `waitlist`). Готовая заполненная база уже включена в проект, а при запуске в пустой папке `DatabaseManager` автоматически создает таблицы и заполняет демонстрационные данные.

## Как собрать проект в `.exe` файл

### Способ 1: Автоматическая сборка `.exe` через GitHub Actions (без установки Qt на ПК)
В проект уже встроен сценарий `.github/workflows/build_windows_exe.yml`. Как только вы загрузите этот проект в свой репозиторий на GitHub:
1. Перейдите во вкладку **Actions** вашего репозитория на GitHub.
2. GitHub автоматически запустит сборку проекта под Windows x64 и прикрепит готовый архив **`RestaurantBooking_Windows_x64`** с `.exe` файлом и базой `restaurant.db`.

### Способ 2: Статическая сборка в один `.exe` на Windows (CMake / MinGW / Qt Creator)
1. Откройте `CMakeLists.txt` или `RestaurantBookingQt.pro` в **Qt Creator**, либо запустите `build_windows_static.bat`.
2. Для статической сборки в один автономный `.exe` файл (при наличии статического профиля Qt, например в MSYS2 MinGW `mingw-w64-x86_64-qt6-static`):
   ```bash
   cmake -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_STATIC_EXE=ON
   cmake --build build --config Release
   ```

### Способ 3: Проверка базы данных SQLite и автотестов через `g++`
```bash
g++ -std=c++17 tests/test_sqlite_db.cpp -lsqlite3 -o restaurant_sqlite_tests
./restaurant_sqlite_tests
```
